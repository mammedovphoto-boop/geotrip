# GEOTRIP — GEORGIA STORIES: бриф второй версии (папка play/)

Адаптация исходного брифа «редизайн в стиле игры с открытым миром» под то, что уже решено на проекте.

## Что остаётся как в основном сайте
- Сборка `python build.py`, один набор страниц и данных на ru/en/ar; вторая версия — те же шаблоны в `dist/play/` со своими `assets/game.css` и `assets/game.js`.
- Реальные маршруты, цены, калькулятор, заявки в WhatsApp, документы. Ничего не имитируется.
- Страница формата («Классик», «Приключение») — один экран: карта + список программ.
- Страница программы — сразу пошаговый опросник, один экран, ниже ничего нет.
- Блок «Пять элементов»: Земля, Воздух, Вода, Огонь и пятый — сам путешественник.
- На карте не пишем «Россия», нет воздушных шаров, год основания 2016.

## Что делает версию «игрой»
- Палитра: #090A14, #FF2D9B, #8A45FF, #00E5FF, #FFC247, #F5F3F0.
- Заголовки — Dela Gothic One (у Anton и Bebas Neue нет кириллицы), интерфейс — Rubik, арабский — IBM Plex Sans Arabic.
- Заставка при входе (раз в 12 часов, можно пропустить): логотип → нарезка рисованных сцен → «Грузия — твоя история начинается здесь» → «Начать приключение» / «Войти без музыки».
- Первый экран: «Это не просто тур. Это твоя история.», три кнопки, параллакс, искры, заголовок по буквам.
- Форматы = режимы (панели постера), программы = миссии, экран «Миссия выбрана» перед переходом.
- Последний шаг опросника: «Mission ready — твоя экспедиция собрана».
- Радио GeoTrip: три своих трека, громкость, следующий трек, память между страницами; звук только после нажатия.
- Достижения в «Пяти элементах», атмосфера раздела меняется вместе со стихией.

## Чего нельзя
- Название, логотип, шрифт, персонажи, музыка и интерфейс GTA — не используются.
